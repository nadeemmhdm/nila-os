# Nila OS

**Experimental AI-native Debian Linux project — developer preview, not a verified operating-system release.**

Nila OS aims to combine an offline-first local AI assistant, explicit permission controls, isolated task workspaces, and a beginner-friendly VM experience.

## Website

[Project website](https://nadeemmhdm.github.io/nila-os/) · [VM setup](docs/VM_SETUP.md) · [Development status](docs/STATUS.md)

## Download

Source: **Code → Download ZIP** on this repository. This initial GitHub publication contains website and documentation; the earlier developer kit is not yet published here. **No bootable Nila OS ISO is available.** Do not download a similarly named image from unofficial sources.

## Local VM development

Install Debian 12 or later XFCE in VirtualBox; allocate 4 GB RAM, 2 vCPU, 35 GB disk where host resources permit. Follow [VM setup](docs/VM_SETUP.md). The OS integration, privileged security controller and live ISO require implementation and independent testing.
