# Nila OS v0.1.0 — Developer Preview

This is the **initial project website and documentation release**, not a bootable operating-system distribution.

## Included
- Responsive project landing page with animated SVG icons and mobile navigation.
- VirtualBox/Debian development VM setup guide.
- Professional project README, contribution and security policies.
- GitHub Pages deployment automation.

## Not included
- Bootable or installable Nila OS ISO.
- Bundled local AI model, model installer, or validated offline voice features.
- Production-ready permission gateway, watchdog, or recovery system.

## Getting started
Read [VM setup](https://github.com/nadeemmhdm/nila-os/blob/main/docs/VM_SETUP.md) to prepare a Debian development VM. The auto-generated GitHub source archives are **source code only**; they cannot be booted or installed as an OS.

## Verification
The website deployment has previously completed successfully; this release does not certify VM boot, offline inference, installation, or security.
