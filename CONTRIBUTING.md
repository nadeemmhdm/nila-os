# Contributing to Nila OS

Thank you for contributing. Nila OS is an experimental Linux/AI project. Start with a GitHub issue describing the problem, expected behavior and proposed scope.

## Development workflow

1. Fork the repository and create a descriptive feature branch.
2. Make focused changes with tests and update relevant documentation.
3. Never commit credentials, model files with incompatible redistribution terms, user data or generated VM disk images.
4. Open a pull request explaining changes, verification commands, risks and rollback instructions.
5. Security-sensitive changes require threat modeling, negative tests and independent review before merge.

## Pull request checklist

- [ ] Tests included or test gap explained
- [ ] Documentation updated
- [ ] No hardcoded credentials
- [ ] No privileged AI execution without authorization
- [ ] License compatibility checked

See [SECURITY.md](SECURITY.md) for private vulnerability reporting.
