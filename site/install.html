GET STARTED

Prepare your
development VM.

No verified bootable Nila OS ISO exists. This guide installs ordinary Debian as a development base, not a finished custom operating system.
01

Download tools

Install VirtualBox and obtain Debian from its official website.

VirtualBox website
Official Debian downloads

02

Create the VM

Suggested: Debian 64-bit, 4 GB guest RAM, 2 vCPU, 35 GB dynamically allocated disk and NAT networking.

03

Install and snapshot

Install Debian with XFCE, create your own password, update packages and save a clean VirtualBox snapshot.

04

Clone the project

sudo apt update
sudo apt install -y git
git clone https://github.com/nadeemmhdm/nila-os.git

This repository currently contains website and documentation source, not an OS installer.
